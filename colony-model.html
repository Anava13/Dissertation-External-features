Colony Model

A branching-process simulation of yeast colony size distributions, written for Supplemental 1 of Alejandro Navarro's PhD dissertation. Build a p(success) trajectory from flat segments, ramps, and branch events, simulate a colony set, and read its histogram, kernel density curve, lognormal mixture fit, and lineage composition. The presets load the condition behind each figure and table of the supplemental.

The simulation runs in this browser with nothing to install. A run reproduces the values reported in the supplemental within simulation noise.

Trajectory builder

Click a line or a branch curve to select it and jump to its controls. Drag a flat line up or down to change phi, or drag a ramp to shift it. A selected segment shows a handle at its end: drag it sideways to change the rounds, or up and down to change phi. On the last segment, the sideways drag sets the total division rounds; a ramp also shows a handle at its start. Drag a branch curve sideways to move the branch round. The dashed line below zero is the arrested pool; select it to add a branch from arrested cells.

Mixture models

Grid presets use these settings for the seed and mixture fitting only; their colonies, rounds, and detection limit come from the preset. A run simulates every colony set; the mixture is fitted when a set is shown, or for every set with Fit all, and each fit is saved with the run.

Results

What each view shows

  • Trajectory: phi(r) for each lineage pool, with eps drawn as a band of two standard deviations. A curve marks each branch event.
  • Histogram: measurable colonies binned on a log radius axis.
  • Kernel density: a Gaussian kernel density of log radius. The mode count comes from a separate density of radius with a Freedman-Diaconis bandwidth (at least 25 µm), counting peaks whose prominence reaches 5 percent of the maximum; dashed red lines mark those peaks.
  • Mixture: the LogNormal model fits a Gaussian mixture to log radius, and the Gaussian model fits one to radius, each for one to five components with the component number chosen by BIC across repeated sweeps. With both models checked, the fit with the lower AIC is shown, with the LogNormal AIC moved to the radius scale (adding 2 times the sum of log radius) so the two compare on the same data. Each component's form, normal or lognormal, is chosen by AIC on the colonies assigned to it.
  • Fit marks on the overview map: an open circle marks a set whose mixture is not fitted yet, a pulsing gold circle a fit in progress, and a filled circle a fit that is done and saved. Each fit draws on its own random stream from the seed, so the order of fitting does not change the result.
  • Branch events: hover over or select a branch curve in a result trajectory for its source and target pools, mode, conditional probability, round, and source compartment.
  • Lineage composition: for colonies that grew on more than one pool, the share of each colony's cells from each pool, averaged within each histogram bin.

Each round, a colony's p(success) is drawn from a beta distribution with mean phi(r) and standard deviation eps, shared by every dividing cell of that pool in that round. Division outcomes are binomial below 500 dividing cells and normal above. Cell counts convert to radius through hemisphere geometry at 0.0113 cells per cubic micrometre. Each colony set runs on its own random stream derived from the seed, so the same seed gives the same results on every run.
